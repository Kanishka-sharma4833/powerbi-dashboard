# HR Analytics Dashboard

An interactive Power BI dashboard designed to analyze workforce data and provide meaningful insights into employee demographics, department distribution, recruitment sources, employee satisfaction, and performance.

## Key Highlights

- Total salary and headcount analysis
- Active and terminated employee analysis
- Department-wise employee distribution
- Recruitment source analysis
- Employee satisfaction analysis
- Employee performance analysis
- Gender and marital-status analysis
- Year-wise filtering

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
