# Netflix Dashboard

An interactive Power BI dashboard designed to analyze Netflix content and provide meaningful insights into movies, TV shows, genres, ratings, countries, and year-wise trends.

## Key Highlights

- Total movies and TV shows analysis
- Movies vs TV shows distribution
- Country-wise content analysis
- Genre-wise content analysis
- Rating-wise content analysis
- Year-wise content trend analysis
- Top genres and categories
- Interactive filtering for content analysis

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
