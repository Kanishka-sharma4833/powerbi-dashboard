# Supermarket Sales Dashboard

An interactive Power BI dashboard designed to analyze supermarket sales performance and provide meaningful insights into sales, profit, products, branches, customer behavior, and payment methods.

## Key Highlights

- Total sales and revenue analysis
- Total profit and profit margin analysis
- Branch-wise sales performance
- Product category-wise sales analysis
- Product line and quantity analysis
- Customer type analysis
- Gender-wise customer analysis
- Payment method analysis
- Monthly and daily sales trends
- Average customer rating analysis
- Interactive filtering for business analysis

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
