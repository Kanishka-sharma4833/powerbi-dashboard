# Blinkit Dashboard

An interactive Power BI dashboard designed to analyze Blinkit sales performance and provide meaningful insights into outlet types, outlet sizes, item categories, fat content, outlet locations, and customer ratings.

## Key Highlights

- Total sales and average sales analysis
- Number of items and average rating
- Outlet establishment trend analysis
- Outlet size-wise sales analysis
- Outlet location/tier-wise performance
- Item type-wise sales analysis
- Low Fat vs Regular product analysis
- Outlet type-wise sales and item analysis
- Interactive filtering for dynamic analysis

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## Dashboard Preview

The dashboard provides an interactive view of Blinkit's sales performance through KPI cards, charts, slicers, and comparative analysis.
