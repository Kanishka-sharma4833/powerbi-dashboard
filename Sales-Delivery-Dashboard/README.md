# Sales & Delivery Performance Dashboard

An interactive Power BI dashboard designed to analyze sales performance, delivery operations, profit, discounts, customers, sales channels, and warehouse performance.

## Key Highlights

- Total sales and revenue analysis
- Total cost and profit analysis
- Total quantity and discount days analysis
- Sales by channel analysis
- Top customer performance analysis
- Monthly sales trend analysis
- Profit analysis by sales channel
- Discount impact analysis
- Warehouse-wise sales performance
- Region-wise performance analysis
- Product-wise sales analysis
- Interactive filtering using product name, sales channel, and region

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
